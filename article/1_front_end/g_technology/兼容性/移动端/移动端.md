# 简介

移动端有很多种设备，主要可以分为两类：

1. Android
2. Ios

以上两个设备类型，一个页面如要对这两个设备进行适配的话，可能有些点需要注意。



- 安卓和 IOS 在页面上通过输入框, 打开小键盘时, 所表现的行为不一致.

  参见: [此处](https://www.cnblogs.com/songyao666/p/18128484). 

  IOS: 会将整个页面往上滚动, 强行出现滚动条, 不会折叠页面. 如果此时头部是 `fixed`, 则会被顶上去, 在可视区域可不见了.

  Android: 会折叠页面(减少页面高度), 如果页面允许出现滚动条, 则滚动条出现, 不允许则不出现.

  解决方法:

  IOS: 聚焦输入框时, 将页面整体往上滚动, 使得固定的头部显现.

  ```ts
  function handleFocusout() {
    // 也可删除 setTimeout, 只是为了防止小键盘打开时, 浏览器还没来得及响应就滚动的问题
    setTimeout(() => {
      document.body.style.height = visualViewport?.height
        ? `${visualViewport?.height}px`
        : `${window.innerHeight}px`;
      // 关键代码, 失焦(小键盘关闭)时滚动到页面顶部.
      // 因为实际上, 当小键盘被打开, 再关闭时, 此时浏览器滚动条可能会不在页面顶部
      window.scrollTo(0, 0);

      // 如果需要在苹果浏览器上不允许滚动
      // document.documentElement.style.overflow = 'hidden';
    }, 100);
  }
  ```
