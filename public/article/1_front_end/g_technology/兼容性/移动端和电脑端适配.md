# 设计

采用移动优先设计, 提供以下 3 个功能:

- 提供 tailwind css
- 提供 css/less
- 提供 rem 适配

设计理念: 默认先为移动设备进行设计, 渐进式为大屏设计, 如:

```tsx
// 先对所有设备设置默认大小
// 再渐进式从小到大为每个设备设计各个尺寸
<div className="p-1 sm:p-2 md:p-6 lg:p-12 xl:p-24 2xl:p-40" />
```

Ref: [tailwind css 响应式设计](https://www.tailwindcss.cn/docs/responsive-design#arbitrary-values)

## rem 适配

通过更改 `html` fontSize 大小, 从而达到 rem 适配效果.

设置路径为: `@/layouts/index`

在此项目中:

- 已假设基础设计稿尺寸为 **750px** (此项目以此尺寸作为基础书写样式, 这非 UI 提供的设计稿尺寸)
- 已假设基础字体大小 **100px** (用来转为 rem)

那么 `html` fontSize 大小应为: `100 * (当前屏幕宽度 / 750)`

- `当前屏幕宽度 / 750`: 求出屏幕宽度比
- `100 * 屏幕宽度比`: 求出当前屏幕宽度比下, fontSize 应该是多少 px

目的: 对需要要进行适配的元素使用 rem,

这样就不需要特意为每个屏幕大小都设置一遍 px.

### 如何让一个元素通过 rem 适配屏幕宽度

1. 基于 `750px html fontSize=100px` 得到当前屏幕宽度下 html fontSize: `100 * 当前屏幕宽度 / 750`

   如: `100 * 375 / 750 = 50`

   注: 此步骤的公式不会改变, 因为 750px 设计稿尺寸是假设的基础设计稿, 不是 UI 出的设计稿尺寸, 所有元素大小基于此来计算.

   即使设计稿尺寸改变, 也只需要做 2 ~ 5 步即可.

2. 得到设计稿尺寸的宽度, 以及元素的宽或者高

   如: 设计稿尺寸 1080px, 元素宽 50px, 高 120px

3. 求出当前屏幕宽度比

   `375 / 1080 = 0.3472`

4. 计算当前屏幕宽度比下, 1080px 屏幕的 50px, 在 375px 屏幕下是多少

   `50px * 0.3472 = 17.36px`

   ```js
   // 第 4 步 和 第 5 步 可以得出以下计算函数
   function getValue(
     elementSize,
     currentScreenWidth = 375,
     uiDesignWidth = 1080,
   ) {
     // 375: 当前屏幕宽度
     // 1080: UI 出的设计稿尺寸
     const ratio = currentScreenWidth / uiDesignWidth;
     return elementSize * ratio;
   }
   ```

5. 将得到的宽度转为 rem

   50: 当前屏幕宽度下, html fontSize 的大小

   `17.36px / 50 = 0.3472rem`

   此步骤可以使用 `px to rem` 插件

   设置 `px to rem` 插件的 `Root Font Size` 值为第 1 步得到的 fontSize 即可, 然后使用 `Alt + Z` 即可转换

```tsx
// 0.12rem = (html fontSize px) * 0.12, 得到 px 值.
<div className="text-[.12rem]">RECOMMENDED</div>
```

### UI 设计稿尺寸修改

当 UI 设计稿尺寸改变, 如: 改变为 375px.

重复 `现有项目如何让一个元素通过 rem 适配屏幕宽度` 此节步骤

- 可以下载插件 `px to rem`, 快速将 px 转为 rem.

- 改变 `px to rem` 插件的 `Root Font Size` 的值

  - 虽然此 Root Font Size 可以一直设置为 100px, 然后设置浏览器窗口为 UI 设计稿尺寸大小来观察样式是否正确

    然后在此基础上, 再进行相应适配.

    但更推荐的做法: 将 `Root Font Size` 设置为 `100 * 当前屏幕宽度 / 750` (固定公式)

    我推荐设置当前屏幕推荐为: 375px

    这样 375px 的 `100 * 375 / 750 = 50`, 就相当于 750 的 100px, 而且更方便查看样式是否正确
