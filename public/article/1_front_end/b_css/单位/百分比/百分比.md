# 子元素不是绝对定位元素

``` html
<!DOCTYPE html>
<html lang="en">
  <style>
    * {
      box-sizing: border-box;
    }

    .container {
      position: relative;
      width: 375px;
      height: 100px;
      padding: 0 10px;
      display: flex;
      flex-wrap: wrap;
    }

    .son {
      /** 相对于父元素的内容区宽度 */
      width: 50%;  
      /** 相对于父元素的内容区高度 */
      height: 100%;
    }

    img {
      width: 100%;
    }
  </style>
  <body>
    <div class="container">
      <div class="son">
        <img src="https://picsum.photos/150/60?random=89" />
      </div>

      <div class="son">
        <img src="https://picsum.photos/150/60?random=90" />
      </div>
    </div>
  </body>
</html>

```

当子元素不是绝对定位元素时, 子元素宽度和高度使用百分比单位, 将相当于容纳块的内容区宽度和高度.

- width: 50%; 

  `(375-20px) * 50%`

  20px 表示左内边距和右内边距

  等于: 177.5



# 子元素不是绝对定位元素

```html
<!DOCTYPE html>
<html lang="en">
  <style>
    * {
      box-sizing: border-box;
    }

    .container {
      position: relative;
      width: 375px;
      height: 100px;
      padding: 0 10px;
      display: flex;
      flex-wrap: wrap;
    }

    .son {
      /** 相对于父元素的宽度 */
      width: 50%;
      /** 相对于父元素的高度 */
      height: 100%;
      position: absolute;
    }

    img {
      width: 100%;
    }
  </style>
  <body>
    <div class="container">
      <div class="son">
        <img src="https://picsum.photos/150/60?random=89" />
      </div>

      <div class="son">
        <img src="https://picsum.photos/150/60?random=90" />
      </div>
    </div>
  </body>
</html>

```

当子元素**是绝对定位元素**时, 子元素宽度和高度使用百分比单位, 将相当于容纳块的宽度和高度, 而不是只是内容区了

- width: 50%; 

  `375 * 50%`

  等于: 187.5
